## 📚 BẢNG TỔNG HỢP 9 LAB

| Bài thực hành                               | Mô tả bài                                                                                                                                                                                                                                                                                             |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Lab 1. I Am Rich**                        | Hiển thị tiêu đề _I am Rich!_ ở phía trên cùng và hình ảnh viên kim cương ở giữa màn hình.                                                                                                                                                                                                            |
| **Lab 2. MiCard**                           | Xây dựng profile cá nhân với avatar và một số thông tin cơ bản.                                                                                                                                                                                                                                       |
| **Lab 3. Dicee**                            | Ứng dụng gieo xúc xắc. Tìm hiểu `StatefulWidget` để quản lý trạng thái giao diện.                                                                                                                                                                                                                     |
| **Lab 4. Magic 8 Ball**                     | Giao diện hiển thị một quả bóng. Khi nhấn vào, nội dung sẽ thay đổi ngẫu nhiên như “Yes”, “No”, “Ask again later”,... Sử dụng state để quản lý trạng thái và lưu số thứ tự ảnh được hiển thị như `ball1`, `ball2`, `ball3`,...                                                                        |
| **Lab 5. Xylophone**                        | Sử dụng package `audioplayers` để phát âm thanh, xây dựng cây đàn Xylophone với 7 nốt nhạc.                                                                                                                                                                                                           |
| **Lab 6. Quizzler**                         | Ứng dụng đố vui với hai lựa chọn Đúng/Sai. Sau mỗi câu trả lời, người dùng có thể theo dõi tiến độ và biết câu nào đã trả lời đúng hoặc sai. Sử dụng `Navigator` để chuyển màn hình và quay lại màn hình bắt đầu.                                                                                     |
| **Lab 7. Boss Level Challenge 1 - Destini** | Ứng dụng mô phỏng câu chuyện phiêu lưu. Tùy vào lựa chọn, người chơi có thể mở khóa các nhánh cốt truyện và đạt đến những kết thúc (Endings) khác nhau. **Nâng cao:** Sử dụng kỹ thuật Prompt Engineering như Chain-of-Thought và Few-shot Prompting để tự động tạo dữ liệu cốt truyện logic, hợp lý. |
| **Lab 8. BMI Calculator - Building**        | Ứng dụng tính chỉ số BMI với nhiều phương thức nhập liệu, giao diện được tối ưu nhằm nâng cao trải nghiệm người dùng (UX). Sử dụng `Slider`, `Snackbar` và `Container` để xây dựng thanh trượt chỉ số BMI.                                                                                            |
| **Lab 9. Clima - Powering Your Flutter**    | Ứng dụng hiển thị nhiệt độ và điều kiện thời tiết dựa trên vị trí hiện tại của người dùng hoặc thành phố bất kỳ được nhập vào.                                                                                                                                                                        |

## 🚀 Hướng dẫn chạy dự án

### 1. Clone repository

```bash
git clone https://github.com/nguyenthily2005/Flutter9LabExercises.git
```

### 2. Di chuyển vào thư mục Lab cần chạy

Ví dụ với Lab 9:

```bash
cd Flutter9LabExercises/lab9
```

### 3. Cài đặt dependencies

```bash
flutter pub get
```

### 4. Chạy ứng dụng

```bash
flutter run
```
